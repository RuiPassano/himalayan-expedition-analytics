# Himalayan Expedition Analytics

## Project Overview

This project analyzes more than 100 years of Himalayan expedition data using SQL and Tableau.

The goal is to clean, validate, model, and analyze historical expedition records in order to identify trends in expedition activity, climbing success, safety, climber demographics, oxygen use, and trekking agency performance.

The project will culminate in an interactive Tableau dashboard that allows users to explore Himalayan expedition history and performance across different peaks, seasons, years, and climber characteristics.

## Project Objectives

- Clean and standardize raw expedition data
- Design a relational analytical data model
- Validate data quality and relationships between datasets
- Perform exploratory and business-focused analysis using SQL
- Identify trends in expedition success, risk, participation, and climbing behavior
- Build an interactive Tableau dashboard
- Present key findings in a professional portfolio case study

## Data Sources

The project uses three datasets:

- Expeditions
- Members
- Peaks

These datasets contain historical information on Himalayan climbing expeditions, participating climbers, expedition outcomes, and mountain characteristics.
